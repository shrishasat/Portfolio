01 · 2026 NEURAL COMPUTING

GPU-Accelerated Neural Representation Searchlight

Built a GPU-accelerated RSA searchlight pipeline for source-level MEG analysis where conventional CPU execution becomes computationally prohibitive.

The system combines MNE inverse modelling, OCT-6 cortical source spaces, temporal-spatial searchlights, Kendall tau similarity, PyTorch tensor operations and batched CUDA execution.

PIPELINE

MEG → preprocessing → dSPM → cortical source space → temporal-spatial searchlight → RDM computation → Kendall τ → group analysis

COMPUTE

A100 GPU · PyTorch · CUDA · batched searchlight computation
